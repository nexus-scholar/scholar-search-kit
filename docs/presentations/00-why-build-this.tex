\begin{frame}{Why Build from First Principles?}
  \begin{block}{Auditability over Convenience}
    We cannot scientifically trust what we cannot trace. Building clean-room components ensures mathematical exactness for deduplication denominators and citation metrics.
  \end{block}
  \vspace{0.3cm}
  \begin{itemize}
    \item \textbf{Resilient Client}: Polite token buckets and SQLite session caching.
    \item \textbf{Anti-Hallucination}: Verification against 150M Crossref records.
    \item \textbf{Agentic Automation}: Native Antigravity skills for AI research assistants.
  \end{itemize}
\end{frame}
